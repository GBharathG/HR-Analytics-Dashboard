# HR Analytics Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **HR Analytics Dashboard built using Microsoft Power BI** to analyze employee data and provide insights into workforce demographics, employee distribution, attrition, and other key HR metrics.

The dashboard transforms raw HR data into interactive visualizations and KPIs that can help HR teams understand workforce patterns and identify areas requiring attention.

## 🎯 Objectives

- Analyze overall employee workforce composition
- Understand employee demographics
- Analyze employee attrition and retention patterns
- Identify trends across different employee groups
- Provide interactive HR KPIs and visual insights
- Enable data-driven HR decision-making

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**

## 📌 Key Dashboard Metrics

- Total Employees
- Attrition
- Attrition Rate
- Average Employee Age
- Average Monthly Income
- Employee Distribution
- Department-wise Analysis
- Job Role Analysis

## 📈 Dashboard Analysis

The dashboard provides analysis across areas such as:

- Employee demographics
- Department-wise employee distribution
- Job roles
- Gender distribution
- Age groups
- Employee attrition
- Income-related analysis
- Workforce characteristics

Interactive filters and slicers allow users to explore the data across different employee segments.

## 💡 Key Insights

The dashboard helps identify:

- Employee groups with higher attrition
- Workforce distribution across departments and roles
- Demographic patterns within the organization
- Differences in employee characteristics across segments
- Areas where HR teams can further investigate retention patterns
